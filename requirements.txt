# ─── PyTorch ──────────────────────────────────────────────────────────────────
# torch/torchaudio/torchvision are intentionally NOT pinned here.
#
# On Vast.ai pytorch containers (and most managed GPU images), torch is
# pre-installed with a CUDA build matched to the host driver. Reinstalling
# torch via pip can downgrade CUDA support and break the GPU. Trust the
# container's torch; only install it yourself on a bare environment via
# https://pytorch.org/get-started/locally/.
#
# Verified compatible with: torch >= 2.2 (incl. 2.11+cu128 on Vast.ai).
